# Projeto Aplicado II – Banco de dados – 2026.1
##🏦 Detecção de Fraudes em Transações Bancárias

📖 Sobre o Projeto

Com o crescimento exponencial das transações digitais, as instituições financeiras lidam com um volume massivo de operações diárias em múltiplos canais, dispositivos e localidades. Nesse cenário, identificar comportamentos suspeitos de forma rápida e precisa é um desafio crítico para a área de dados.

Este projeto foca no desenvolvimento de uma solução analítica para a indicação de possíveis fraudes bancárias. Indo além de uma análise puramente descritiva, o objetivo é criar um produto analítico que apoie a tomada de decisão, gerando alertas de risco sobre transações potencialmente fraudulentas por meio de modelos preditivos.

O fluxo de trabalho abrange desde uma rigorosa Análise Exploratória de Dados (AED) para mapeamento de comportamentos e anomalias, até a aplicação prática de algoritmos de classificação.

🎯 Objetivos

Objetivo Geral
Desenvolver uma solução analítica baseada em dados transacionais para detectar e alertar sobre possíveis fraudes bancárias, unindo técnicas de Análise Exploratória de Dados (AED) e Machine Learning.

Objetivos Específicos
Tratamento de Dados: Compreender a estrutura do dataset, realizando a limpeza, organização e padronização das informações.

Análise Exploratória: Explorar o comportamento das transações investigando variáveis chave (valor, canal, localização, dispositivo e perfil do cliente).

Detecção de Anomalias: Identificar padrões atípicos e inconsistências estatísticas associadas ao risco de fraude.

Modelagem Preditiva: Construir, treinar e validar modelos de Machine Learning focados na classificação de transações de alto risco.

Geração de Insights: Extrair inteligência acionável para aprimorar as regras de negócios e os processos de prevenção de fraudes.

🛠️ Tecnologias e Ferramentas

As principais tecnologias utilizadas para o desenvolvimento desta solução incluem:

Linguagem: Python

Análise e Manipulação de Dados: Pandas

Visualização de Dados: Matplotlib, Seaborn

Estatística e Machine Learning: Scikit-learn, Statsmodels

Ambiente de Desenvolvimento: VS Code integrado com Anaconda
